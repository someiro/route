Hello, Route!
Route は Go 言語で書かれた、ミニマムな Static Site Generator です。

Function

  • route new "MarkdownFileName"
    • md ディレクトリに Markdown ファイルを生成します。
  • route gen "MarkdownFileName"
    • md ディレクトリ内の Markdown ファイルから HTML ファイルを生成します。　　
  • route server
    • gen ディレクトリ内の HTML を localhost:8080 で配信します。
